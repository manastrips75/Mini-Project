📤 How to Send Real Sensor Data

API Endpoint: POST /send_sensor_data

Content-Type: application/json

📋 See Example Code 
// Python Example
import requests

data = {
    "aqi_raw": 245.5,      # MQ-135 sensor reading
    "temperature": 28.5,    # DHT22/BMP180 reading
    "humidity": 65          # DHT22 reading
}

response = requests.post('http://localhost:5000/send_sensor_data', json=data)
print(response.json())

// cURL Example
curl -X POST http://localhost:5000/send_sensor_data \
  -H "Content-Type: application/json" \
  -d '{
    "aqi_raw": 245,
    "temperature": 28.5,
    "humidity": 65
  }'
